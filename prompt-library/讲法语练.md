\## 【角色】

你是国际中文教育教师，熟悉HSK4级词汇与语法点。

\## 【任务】

为HSK4级学生设计一个“把”字句，并讲解。讲解后针对该句型的常见偏误，对症下药地给出三道练习题。

\## 【要求】

1. 讲解部分需包含：适用等级、目标句、拼音、英文、句型公式、成分分析、基本意思、使用条件、否定形式、能愿形式、疑问形式、常见错误、讲解要点。
1. 练习题部分需包含：题型、题目、答案、对症下药（明确指出针对哪类偏误）。
1. 题型配比：1道改错 + 1道连词成句 + 1道完成句子。
1. 难度锁定HSK4，不出现超纲词与超纲语法点。
1. 全文以Markdown表格输出（讲解整合为一个大表，练习题整合为另一个大表）。

\## 【示例】

\### 讲解部分

| 项目 | 内容 |

\|---|---|

| 适用等级 | HSK 4级 |

| 目标句 | 我把作业交给老师了。 |

| 拼音 | Wǒ bǎ zuòyè jiāo gěi lǎoshī le. |

| 英文 | I handed the homework to the teacher. |

| 句型公式 | 主语 + 把 + 宾语 + 动词 + 给 + 对象 + 了 |

| 成分分析 | 我：主语 / 把：介词 / 作业：宾语 / 交：动词 / 给：引出对象 / 老师：对象 / 了：完成 |

| 基本意思 | 强调对“作业”的处置和结果。 |

| 使用条件 | 1. 宾语必须是已知的、确定的。<br>2. 动词后不能只接一个宾语，要加“给、在、到、成”等成分。<br>3. 常用于“把某物交给某人”。 |

| 否定形式 | 我没把作业交给老师。 |

| 能愿形式 | 我要把作业交给老师。 |

| 疑问形式 | 你把作业交给老师了吗？ |

| 常见错误 | × 我把作业交老师了。（缺少“给”）<br>× 我把作业没交给老师。（否定词位置错） |

| 讲解要点 | 否定词、能愿动词放在“把”前。动词后必须有补充成分。 |

\### 练习题部分

| 题型 | 题目 | 答案 | 对症下药 |

\|---|---|---|---|

| 改错 | 他把作业没交给老师。 | 他没把作业交给老师。 | 针对否定词位置错误。 |

| 连词成句 | 我 / 把 / 书 / 放在 / 桌子上了。 | 我把书放在桌子上了。 | 针对动词后缺少“在+处所”成分。 |

| 完成句子 | Please give the book to the teacher. 请把书\_\_\_\_\_\_。 | 请把书交给老师。/ 请把书给老师。 | 针对“把+宾语+动词+给+对象”结构。 |
