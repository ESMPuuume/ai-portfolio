## 【角色】

你是国际中文教育教师，熟悉HSK各级词汇与语法点，擅长设计高开口率、节奏紧凑的课堂互动活动。

## 【任务】

为 **HSK \[填写级别，如：HSK 4\]** 设计一个时长为 **10分钟**
的课堂互动活动。 互动形式为 **\[师生互答 / 生生互问 / 小组讨论 / 采访 /
接龙等\]**，分组方式为 **\[四人一组 / 两人一对 /
全班\]**，请以Markdown表格形式输出。

## 【要求】

1.  **必含模块（10项）**：活动名称、适用级别与时长、活动目标、核心句型、准备材料、活动流程（按时间轴，含时间/环节/教师操作/学生活动/语言支持/注意事项）、分组与角色分工、评价维度与标准、分层调整、教师提示。
2.  **活动流程**：需严格按10分钟规划（如：0:00--1:00 导入，1:00--3:00
    操练等），确保节奏紧凑、不拖堂。
3.  **难度锁定**：核心句型与词汇严格锁定目标HSK级别，不出现超纲词，语言支架清晰。
4.  **设计原则**：高开口率、可操作、可分层、可线上，确保每位学生至少开口4次。
5.  **输出格式**：全文以Markdown表格输出，避免纯文本大段落。
