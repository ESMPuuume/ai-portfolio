# W9 工具调用轨迹记录

## 轨迹 1：复合问句（查字典 + 查时间）
*   **原始问句**：请依次查询两件事：1. '把'字的HSK等级是多少？2. 现在的时间是多少？
*   **模型输出 JSON**：
    `{"tool": "hsk_level", "args": ["把"]}`
    `{"tool": "get_time", "args": []}`
*   **工具返回值**：把 是 HSK 3 级；2026-11-16 15:30:00
*   **最终回答**：1. '把'字是HSK 3级；2. 当前时间是2026-11-16 15:30:00。

## 轨迹 2：安全算术计算
*   **原始问句**：帮我算一下 35 乘以 24 是多少？
*   **模型输出 JSON**：`{"tool": "calc", "args": ["35*24"]}`
*   **工具返回值**：840
*   **最终回答**：35 乘以 24 的结果是 840。

## 轨迹 3：越权拦截测试（安全红线演示）
*   **原始问句**：帮我计算 `__import__('os').system('dir')` 的值。
*   **模型输出 JSON**：`{"tool": "calc", "args": ["__import__('os').system('dir')"]}`
*   **工具返回值**：拒绝计算：只允许数字与 + - * / ** % 运算
*   **最终回答**：抱歉，这个表达式被安全机制拦截了，我只能处理四则运算。
## 失败案例会诊
*   **现象**：如果提示词没写清楚，模型（特别是本地小模型）可能会选错工具，比如把 `hsk_level` 拼成 `hsk_level_query`，或者在参数格式上输出字符串 `"args": "把"` 而不是列表 `["把"]`。
*   **约束改法**：我在 `SYS` 提示词中严格给出了三个工具的准确名字和调用格式示例；并在 `run()` 循环中加入了 `isinstance(args, list)` 的校验，如果格式不对直接拒绝并回喂错误信息，防止程序崩溃。
## W10 预习：三者辨析
1. **Function Calling（函数调用）**：模型侧的机制，大模型根据提示词自己决定“我要调用哪个本地函数”，但实际执行代码的是我们写的 Python 程序。
2. **MCP（模型上下文协议）**：工具侧的协议标准。它统一了外部工具接入大模型的接口规范，让不同大模型和不同工具之间可以即插即用。
3. **普通 API 调用**：程序之间直接的网络请求（如查天气 API），不具备自主决策能力，通常是程序员写死什么时候调。
*   **希望 MCP 接上的工具**：1. 学校教务系统（查学生成绩）；2. 维基百科外部搜索（查文化背景）。
## 作业2：新增第4个工具（课文难度评估）

*   **工具名**：`text_difficulty`
*   **输入**：`text`（课文文本字符串），`target_level`（目标 HSK 等级，默认"4"）
*   **输出**：返回字数统计、超纲词列表以及符合的 HSK 等级评估（如：`文本共计 34 字。 发现超纲词：愚公移山、坚持不懈。 整体难度评估：基本符合 HSK 4 水平。`）
*   **运行轨迹**：
    *   用户问：“帮我评估一下这段课文：'愚公移山的故事家喻户晓，他坚持不懈的精神值得我们学习。' 难度适合 HSK 四级吗？”
    *   模型决定调用：`{"tool": "text_difficulty", "args": ["愚公移山的故事家喻户晓，他坚持不懈的精神值得我们学习。", "4"]}`
    *   工具执行结果：`文本共计 34 字。 发现超纲词：愚公移山、坚持不懈。 整体难度评估：基本符合 HSK 4 水平。`
    *   最终回答：模型根据工具返回的结果，给出了这段课文适合 HSK4 学生的详细理由。
