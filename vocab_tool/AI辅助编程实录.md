# AI辅助编程实录

## 1. 任务与提示词

**做什么**：读生词表CSV -> 筛选HSK4 -> 统计词性分布 -> 生成练习.txt闪卡文件
**我写的提示词**（使用四件套结构）：

```text
【角色】
你是Python教学助手，熟悉标准库（csv、os）与文件路径处理，不提供超纲代码。

【任务】
写一个名为 vocab_tool.py 的脚本，读取本地的生词表CSV文件，筛选HSK4词汇，统计词性分布，并自动生成一份练习题。

【要求】
1. 输入：读取 data/生词表.csv（字段包含：词汇, HSK等级, 词性, 拼音, 释义）。
2. 处理：定义四个函数：load_words（读）、filter_by_level（筛）、count_by_pos（统）、gen_exercises（写）。筛选条件为 HSK等级 == "4"。统计筛选后词汇的词性分布（使用字典计数，注意避免 KeyError）。
3. 输出：终端打印总词汇数、HSK4词汇数、词性分布。在代码包根目录生成 练习.txt。
4. 严格约束（非常重要）：只使用标准库（csv、os），禁止使用 pandas 等第三方库，不使用 argparse 等高级写法。文件读写必须显式加上 encoding="utf-8"。
*   **修改点6（扩展功能）：按词性分组输出**
    *   *改了什么*：新增了 `group_by_pos` 函数，并在主程序中调用。
    *   *为什么*：原先的 `count_by_pos` 只能统计数量，无法看清具体有哪些词。新增的 `group_by_pos` 能够将 HSK4 的词汇按词性归类打印，生成类似“【动词】：坚持、商量”这样的列表。这对于词汇课的按词性复习非常直观，方便老师分派学习任务。
