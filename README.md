# ai-portfolio

> 💡 **给互评同学/老师的提示**：
> 您好！感谢评阅。本项目（W8阶段项目一）的 `assistant_v1.py` 依赖本地的 Ollama。如果您本地未启动 Ollama，程序会自动触发回退机制切换至云端，**绝对不会崩溃报错**。
> 如需体验最快响应速度，请配置好 `.env` 密钥，并在运行参数加上 `--prefer api`。此外，我的 RAG 检索手写了 0.55 的防幻觉阈值，欢迎测试提问无关问题（如“今天天气如何”），它会被直接拦截。

## 📖 项目简介
本仓库是《人工智能在学习环境中的应用与实践》课程的个人作品集（贯穿 16 周）。

我以**国际中文教育（对外汉语）教师**的视角，探索如何利用 AI 对话工具与 Python 编程，辅助日常教学资源的设计与开发。目前，本仓库已沉淀了标准化的 AI 提示词库、生词处理脚本、云端与本地大模型调用、**双引擎统一封装架构**、**手写 RAG 知识库问答器**，以及**可交付的阶段项目 v1.0（学科智能问答助手）**。这不仅是一份代码作业，更是一次从“AI 使用者”向“AI 架构师”进阶的探索之旅。
