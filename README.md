# ai-portfolio

## 📖 项目简介
本仓库是《人工智能在学习环境中的应用与实践》课程的个人作品集（贯穿 16 周）。

我以**国际中文教育（对外汉语）教师**的视角，探索如何利用 AI 对话工具与 Python 编程，辅助日常教学资源的设计与开发。目前，本仓库已沉淀了标准化的 AI 提示词库、自动化生词处理脚本、云端与本地大模型调用、**双引擎统一封装架构**，以及**基于纯原生 Python 手写的 RAG（检索增强生成）知识库问答器**。这不仅是一份代码作业，更是一次从“AI 使用者”向“AI 架构师”进阶的探索之旅。
