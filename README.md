# ai-portfolio

## 📖 项目简介
本仓库是《人工智能在学习环境中的应用与实践》课程的个人作品集（贯穿 16 周）。我以**国际中文教育（对外汉语）教师**的视角，利用 AI 对话工具（如deepseek）辅助教学设计，沉淀了一套结构化的 AI 教学提示词库（Prompt Library）。

## 📂 目录结构
本仓库包含基础验证脚本、AI 任务记录以及核心的提示词库。提示词库（`prompt-library/`）中的每个文件均遵循【角色】【任务】【要求】【示例】四件套结构，包含完整的“提示词”、“适用说明”和“最佳示例”。

```text
ai-portfolio/
├─ README.md                 // 本说明文件（仓库总览）
├─ hello.py                  // Python 配置与环境验证脚本
├─ ai任务单.md               // 记录使用 AI 完成学科任务的完整过程与成果
└─ prompt-library/           // 核心提示词库
   ├─ 出题.md
   ├─ 迭代实录.md
   ├─ 讲法语练.md
   ├─ 教案扩展.md
   ├─ 课堂活动.md
   ├─ 口语话题设计.md
   ├─ 生词筛查.md
   ├─ 听力理解题设计.md
   └─ 作文批改.md
