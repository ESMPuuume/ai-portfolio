# 开源项目拆解阅读笔记

1. **2-Step RAG 是什么**：它是指“检索总在生成之前”的 RAG 架构。系统先根据用户问题检索出相关文档片段，再将其与问题一起拼成提示词交给大模型生成答案。它简单可预测、LLM 调用次数有上限，非常适合 FAQ 和文档机器人。
2. **llm-universe C3 做了什么**：C3 章节讲解了数据处理与向量化，包括文本的读取清洗与切片、Embedding API 的使用，以及如何搭建并使用向量数据库。
3. **llm-universe C4 做了什么**：C4 章节讲解了如何将大模型接入 LangChain、基于 LangChain 搭建检索问答链，以及如何使用 Streamlit 将其部署为可视化助手。
